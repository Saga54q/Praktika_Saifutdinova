# Модуль регистрации и учёта заявок на техническое обслуживание

Учебная практика УП.04 «Инсталляция, настройка и обслуживание программного обеспечения компьютерных систем»  
Организация: ООО «Техсервис»  
Модуль: регистрация и учёт заявок на техническое обслуживание компьютерной техники и программного обеспечения.

## Назначение

Модуль является первым компонентом модульной информационной системы ООО «Техсервис». Он предназначен для регистрации, хранения, поиска, фильтрации и обработки заявок на техническое обслуживание.

Остальные модули (учёт оборудования, история обслуживания и ремонтов, отчётность и аналитика, управление пользователями и разграничение доступа) рассматриваются как перспективы развития и в текущей практике не реализуются.

## Возможности

- создание новой заявки;
- просмотр списка заявок;
- редактирование заявки;
- удаление заявки с подтверждением;
- поиск по номеру и другим параметрам;
- фильтрация по категории и статусу;
- изменение статуса заявки;
- просмотр подробной информации о заявке;
- сохранение данных в SQLite;
- проверка корректности вводимых данных.

## Стек

- Python 3
- Tkinter
- SQLite (`sqlite3`)
- `unittest` для автоматических тестов

## Запуск

1. Перейти в каталог проекта:

```bash
cd TechService
```

2. Запустить приложение:

```bash
python main.py
```

При первом запуске автоматически создаётся файл базы данных `TechService/data/techservice.db`.

## Тестирование

Запуск автоматических тестов из каталога `TechService`:

```bash
python -m unittest discover -s tests -v
```

Проверяемые сценарии:
- создание заявки;
- редактирование заявки;
- удаление заявки;
- поиск;
- фильтрация;
- изменение статуса;
- сохранение и повторное получение данных после перезапуска;
- обработка некорректного ввода.

## Данные заявки

- уникальный идентификатор;
- дата регистрации;
- заказчик или подразделение;
- тип оборудования;
- категория обращения;
- описание неисправности;
- приоритет;
- текущий статус;
- описание выполненных работ.

## Категории обращений

- неисправность оборудования;
- установка программного обеспечения;
- обновление программного обеспечения;
- настройка программного обеспечения;
- диагностика;
- прочее.

## Статусы

- новая;
- в работе;
- выполнена;
- отменена.
